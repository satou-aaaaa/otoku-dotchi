# どっちがお得？（otoku-dotchi）

3割引と500円引き、どっちが安い？ 割引・%オフ・ポイント還元・100gあたり・まとめ買い・税込と税抜を計算して、お得なほうを当てる1日5問の学習ゲーム。正解したら「どう計算した？」も選びます。

遊ぶ：https://satou-aaaaa.github.io/otoku-dotchi/

- 割合の計算は小学校5年の算数「割合（百分率）」、消費税は標準税率10%で計算します（2026-11-17 に読んだ資料）。
  - [文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」](https://www.mext.go.jp/a_menu/shotou/new-cs/1387014.htm)（第5学年 割合（百分率））
  - [国税庁 タックスアンサー No.6902「総額表示」の義務付け](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6902.htm)（値段は税込で表示する）
  - [国税庁「軽減税率制度の概要」](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/01.htm)（標準税率10%・軽減税率8%。軽減税率は時期によって変わるため問題にしていません）
- 品物・お店・値段は練習用の作り話です。1円未満の端数の扱いやポイントのきまりは、お店によってちがいます。
